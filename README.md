#  Inventory Management System (Fool of a Took LTDA)

##  About
This project is an Inventory Management System developed in Python. It was designed to address core organizational challenges, providing a clean Command-Line Interface (CLI) to manage product registration, stock monitoring, and data persistence using JSON files.

##  Key Features
- **Data Persistence:** Uses JSON to save and load inventory data, ensuring information is stored securely between sessions.
- **Efficient CRUD Operations:** Seamless creation, reading, updating, and deletion of inventory items.
- **Modular Design:** Built with a focus on clean code and logical structure, applying concepts of functions and modularization to ensure scalability.
- **Process Optimization:** Reflects a professional focus on accurate stock control and workflow management.

##  Technologies
- **Language:** Python 3.x
- **Data Format:** JSON
- **Concepts:** Data structures, Error handling, Modular programming.
