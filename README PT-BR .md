#  Sistema de Gestão de Inventário (Fool of a Took LTDA)

##  Sobre
Este sistema foi desenvolvido como uma atividade acadêmica para a disciplina de Gestão da Tecnologia da Informação. O objetivo foi criar uma aplicação funcional em Python para o controle de estoque de uma empresa fictícia, unindo lógica de programação a práticas de organização e gestão de dados.

## ️ Funcionalidades Principais
- **Persistência de Dados:** Utilização de arquivos JSON para garantir que as informações de estoque sejam mantidas entre execuções.
- **Controle de Itens:** Realização de cadastro, consulta, atualização e remoção de produtos (CRUD).
- **Interface Intuitiva:** Interface via terminal (CLI) pensada para facilitar o uso e garantir a eficiência nas rotinas administrativas.
- **Foco em Processos:** Código estruturado para refletir a importância da precisão e do controle rigoroso de insumos.

##  Tecnologias Utilizadas
- **Linguagem:** Python 3.x
- **Formatos:** JSON
- **Conceitos:** Estruturas de dados, tratamento de erros e modularização.
